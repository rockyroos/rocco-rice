# Design system

The setup is mostly Nord, with a few practical deviations where an app or upstream theme already had a good base.

| Role | Value |
|---|---|
| Base | `#2E3440` |
| Surface | `#3B4252` |
| Hover | `#434C5E` |
| Border | `#4C566A` |
| Text | `#ECEFF4` |
| Muted text | `#D8DEE9` |
| Frost | `#88C0D0` |
| Blue | `#81A1C1` |
| Teal | `#8FBCBB` |
| Green | `#A3BE8C` |
| Yellow | `#EBCB8B` |
| Orange | `#D08770` |
| Red | `#BF616A` |
| Purple | `#B48EAD` |

**Font:** JetBrains Mono / JetBrainsMono Nerd Font  
**Corners:** mostly 0–2 px  
**General direction:** compact, square, minimal, keyboard-first

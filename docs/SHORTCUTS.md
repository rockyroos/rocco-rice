# GlazeWM shortcuts

These are the shortcuts from my current config.

| Shortcut | Action |
|---|---|
| `Alt+Enter` | Open Windows Terminal |
| `Alt+B` | Open Explorer |
| `Alt+H/J/K/L` or arrows | Focus window |
| `Alt+Shift+H/J/K/L` or arrows | Move window |
| `Alt+Ctrl+H/L` | Focus workspace on other monitor |
| `Alt+Ctrl+Shift+H/L` | Move window to workspace on other monitor |
| `Alt+R` | Resize mode |
| `Alt+Shift+P` | Pause/resume GlazeWM |
| `Alt+V` | Toggle tiling direction |
| `Alt+Space` | Cycle tiling/floating/fullscreen focus |
| `Alt+Shift+Space` | Toggle centered floating |
| `Alt+T` | Toggle tiling |
| `Alt+F` | Toggle fullscreen |
| `Alt+M` | Toggle minimized |
| `Alt+Q` | Close window |
| `Alt+A/S` | Previous/next active workspace on monitor |
| `Alt+D` | Recent workspace |
| `Alt+1…9` | Focus workspace |
| `Alt+Shift+1…9` | Move window and follow it |
| `Alt+Shift+R` | Reload config |
| `Alt+Shift+W` | Redraw |
| `Alt+Shift+E` | Exit GlazeWM |

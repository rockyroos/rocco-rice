# Windows Terminal

The terminal shown in my screenshots is Windows Terminal with PowerShell 7.

At the time I captured this setup, my active PowerShell profile used:

```text
Font: JetBrainsMono Nerd Font
Font size: 10
Color scheme: One Half Dark
Opacity: 90%
Acrylic: enabled
```

This is intentionally documented instead of shipping an old Nord terminal preset, because the live setup had already moved away from that preset.

I use Fastfetch and btop4win++ inside the terminal for the system-info views shown in the screenshots.

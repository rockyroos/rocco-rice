# Nilesoft Shell

These are the two Nilesoft files I currently customize.

## File locations

```text
shell.nss  -> C:\Program Files\Nilesoft Shell\shell.nss
theme.nss  -> C:\Program Files\Nilesoft Shell\imports\theme.nss
```

`shell.nss` still imports the other standard Nilesoft files such as `images.nss`, `modify.nss`, `terminal.nss` and `taskbar.nss`. Those are part of the Nilesoft installation and aren't redistributed here.

The repo copy also leaves out an old `Hello, World!` test menu item that was still present in my live file when I captured the setup.

Back up your own files before replacing anything. Nilesoft configs are easy to tweak, so I'd recommend copying only the parts you want rather than blindly overwriting a working setup.

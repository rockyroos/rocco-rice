# Spicetify

My Spotify setup uses **Spicetify**, the **Sleek** theme and its **Nord** color scheme.

I don't redistribute the full Sleek theme here. `rocky-nord-overrides.css` only contains the extra CSS I added on top for JetBrains Mono, sharper corners, Nord/Frost interaction states, scrollbars and a few layout fixes.

I also use Full App Display for the fullscreen music view shown in the screenshots.

Because Spotify's internal class names can change, these overrides may need small fixes after Spotify or Spicetify updates.

# Fountain of Colors

The desktop equalizer shown above my clock is **Fountain of Colors** for Rainmeter.

I don't redistribute the original skin files here. Install the skin from its original project first:

- https://github.com/alatsombath/Fountain-of-Colors

Then use these values as a reference for the look shown in my screenshots:

```text
Bands = 64
BarGap = 1
BarWidth = 5
BarHeight = 400
MinBarHeight = 1
PaletteColor1 = 136,192,208   # Nord Frost / #88C0D0
FFTSize = 2048
FFTBufferSize = 16384
FFTAttack = 0
FFTDecay = 0
FreqMin = 20
FreqMax = 16744.03618
Sensitivity = 24
AverageSize = 4
Colors = Single
TransitionTime = 12
OpacityLower = 255
OpacityUpper = 255
OpacityMultiplier = 1
DecayEffect = 0
Angle = 0
Invert = 0
Channel =
Port =
```

My local audio endpoint/device ID is intentionally not included because it is machine-specific. Select the correct audio device on your own system instead.

This Rainmeter visualizer is separate from the smaller Cava visualizer used in YASB.

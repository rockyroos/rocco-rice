# Rainmeter

I use Rainmeter for two desktop elements:

- `NordClock.ini` — my large clock/date skin
- Fountain of Colors — the desktop audio equalizer above the clock

## NordClock

The included `NordClock.ini` is the current clock configuration used in the screenshots.

It uses **Sharp Grotesk 23** on my machine. The font file is **not included** in this repo; use your own installed copy or substitute another font if needed.

## Fountain of Colors

Fountain of Colors is a separate third-party Rainmeter skin, so I don't redistribute the skin itself. See [`fountain-of-colors/README.md`](fountain-of-colors/README.md) for the original project link and the settings I use.

The desktop Fountain of Colors visualizer is separate from the smaller Cava visualizer in YASB.
